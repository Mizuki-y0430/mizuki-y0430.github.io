SUPPORT & DATA DELETION

連携解除・データ削除・お問い合わせ

最終更新日：2026年10月3日

1. Google連携を解除する

  1. COMPOTAを実行している端末でBotを停止します。常時起動サービスを設定している場合は、そのサービスも停止します。
  2. Googleアカウントのサードパーティ接続管理 を開き、連携に使ったGoogleアカウントでログインします。
  3. COMPOTA、または認証時に表示されたアプリ名の接続を選び、アクセス権や接続を削除します。画面上の名称はGoogleの表示に従ってください。

以降、再認証するまでGoogleカレンダーの操作はできなくなります。Google側の詳細な案内は サードパーティ接続の管理方法 をご覧ください。

アクセス許可を取り消しても、作成済みの予定、Discordメッセージ、端末内のデータは残ります。削除したい情報に応じて、次の手順も実施してください。

2. 実行端末の保存データを削除する

端末の管理者が、Botを停止した状態で以下のファイルを削除してください。設定で保存場所を変更した場合は、変更後の場所が対象です。

  • secrets/google_token.json：Googleの認証情報。
  • data/compota.db：予定のローカル記録、会話状態、処理済みメッセージの返信。
  • data/compota.db-wal、data/compota.db-shm：存在する場合のSQLite関連ファイル。
  • 他の端末、バックアップ、移行用コピーに保存した上記の情報。
  • 保存した運用ログ：ログの保存先や保持期間は実行環境の設定に従います。

利用を完全に終了する場合は、不要になった .env、secrets/google_oauth_client.json 等の設定・秘密情報も削除してください。Discord Botの認証情報が漏れた可能性がある場合は、Discord Developer Portalでトークンを再発行してください。

データベースを削除すると、直近の操作対象、再試行、復元、既存の操作ボタンの管理情報が失われます。予定をBotで整理したい場合は、連携解除・ローカルデータ削除の前に行ってください。Googleカレンダーの予定自体はデータベース削除では消えません。

3. Googleカレンダーの予定を削除する

Googleカレンダーで、COMPOTAが作成した不要な予定を確認して削除してください。利用を続ける場合はBotの削除機能も使用できますが、Botで予定を削除してもローカル記録は残る場合があります。本アプリ以外で作成した予定を誤って削除しないよう、対象を確認してください。

4. Discordのメッセージを削除する

Discordで、自分が送信した予定の指示や、権限のあるBotの返信を削除してください。自分で削除できない投稿はサーバー・チャンネル管理者へ依頼してください。Google連携の解除や端末内データの削除では、Discord上の投稿は消えません。

5. 第三者に運用を依頼している場合

Botの実行端末を自分で管理していない場合は、その運用担当者へ端末内データ・認証情報・バックアップの削除を依頼してください。開発者は、管理していない端末のデータを直接削除できません。

6. お問い合わせ

開発・本サイト管理：Mizuki-y0430

機能の質問、不具合報告、プライバシーポリシーや情報の取り扱いの相談は、calendar-bot のGitHub Issues からご連絡ください。投稿にはGitHubアカウントが必要です。使用バージョン、実行環境、個人情報を含まない再現手順があると確認しやすくなります。

GitHub Issuesは公開されます。予定の具体的な内容、メールアドレス、DiscordのID、認証トークン、OAuth JSON、データベース、個人情報を含むログを投稿しないでください。個別データの確認が必要な相談は、まず内容を伏せて対応方法をお問い合わせください。

返信の時期や対応の完了を保証するものではありません。第三者の実行端末にある個別データについては、端末の運用担当者への連絡も必要です。
